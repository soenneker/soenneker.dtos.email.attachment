# Soenneker.Dtos.Email.Attachment

A DTO type for email attachment encapsulation.

## Install

```bash
dotnet add package Soenneker.Dtos.Email.Attachment
```

## What you get

- `EmailAttachmentDto` — A DTO type for email attachment encapsulation.

## API at a glance

| API | What it does | Result / important behavior |
| --- | --- | --- |
| `EmailAttachmentDto.FileName` | Gets or sets file name. | Gets or sets file name. |
| `EmailAttachmentDto.Data` | Gets or sets data. | Gets or sets data. |
| `EmailAttachmentDto.MimeType` | Gets or sets mime type. | Gets or sets mime type. |
